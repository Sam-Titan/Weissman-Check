Weissman Check

…and the numbers that actually matter. · Scope · draft

Upload a text-like file, run it through six real lossless compressors, and see which one to ship, with an explanation of why.

The Unique Kernel

Seeing why, not just which. After the real benchmark, the app shows a real analysis of your own file (repeated strings an LZ-style compressor would exploit) with a narration card per algorithm. It is an explanation, not live compressor internals. Beside it: which compressor to ship, and whether a single score misleads.

Who → Loop → Proof

Who It's For

Developers only: web and backend developers choosing a compression library for API responses, static assets, logs or backups, who default to gzip today.

Identity

Its own retro-startup look with no show branding. The Weissman score appears as a metric. Nostalgic, easy to understand, impressive UI/UX.

What "Working" Looks Like

In one minute: open the app, read the narrator box, upload a text-like file, select compressors and run. See the metrics and Weissman scores, then the repeated-strings visualization of your file with a narration card per algorithm, then a "ship this one" recommendation.
